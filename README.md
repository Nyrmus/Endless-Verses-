# Endless Verses

2.5D Browser-Game mit mehreren Versen und Kraftsystemen.

## Spielen (v0.1)

`index.html` im Browser öffnen (Datei doppelklicken oder Live Server).

Steuerung: A/D oder Pfeile, Springen mit Leertaste oder W.
Vers: Taste `1` Hub, Taste `2` Soul.

Quelle ist dieses Repo. Chat ist nur Werkzeug.

Siehe `PLAN.md` und `STRUCTURE.md`.
